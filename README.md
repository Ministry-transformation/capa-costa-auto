# Capa Costa Auto

Bilingual Spanish and English website for Capa Costa Auto in Torrevieja.

- Spanish: `/es/`
- English: `/en/`

This is a static GitHub Pages site. The images are generated illustrations and are labeled as such. Current stock, prices, address, hours, legal identity, and contact handling are not confirmed in this preview. The pages retain `noindex, nofollow` until those details are approved.

Website developed by [Ministry of Transformation](https://ministry-transformation.github.io/).
